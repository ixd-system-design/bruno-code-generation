# Code Generation in Bruno
This is a simple demo that includes a short JavaScript code snippet that was [Generated by Bruno](https://docs.usebruno.com/send-requests/REST/code-generator). You may find it useful to test APIs in Bruno, and then generate a code snippet to help migrate the results of your testing into JavaScript. This process may help to jumpstart the creation of dynamic webpages. Bruno by default will generate code that performs an HTTP request, and logs the result to the console. To see this in action, open the browser's Console. (e.g. Right-click > Inspect ). You should see that the console contains JSON data from the API. You can Read more about Bruno's Code Generation features here: [https://docs.usebruno.com/send-requests/REST/code-generator](https://docs.usebruno.com/send-requests/REST/code-generator).


# Try it yourself
Try making your own simple HTML page with embedded Javascript. Use Bruno to form an API request, and then use code generation to jumpstart a script. Copy paste it into your page and see what you can make.
